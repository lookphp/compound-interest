## 排版说明（参考你发的那篇「大数字 + PART」风格）

正文的每个小节都是四行一组，发布时请在秀米 / 135 编辑器里套用「大数字 + PART + 小标题 + 英文副标」模板：

```
01
PART
它实际替我干了哪些活
TASKS
```

- 大数字（01、02…）和 `PART` 是装饰性排版，英文副标（TASKS / BUG / ROLES / COMPOUND / TRY / LIMIT / LAST）是栏目标签，随意换词也行。
- 段落都写得很短，复制进编辑器后保持「一段一行、段间空一行」即可，别合并。
- 结尾的 `///` 和「写在最后 / LAST」也是那篇的招牌，建议保留。
- 图片为可选：放在对应小节开头或结尾都行；不想用图，直接删掉正文里 `![图](assets/...)` 那一行即可，不影响排版。

## 配图 1 · 封面（头图，放在标题下）

> 扁平插画风，明亮温暖配色。画面左侧一个轻松坐着的人，手托下巴，头顶冒出一颗发光的灯泡（代表想法），面前漂浮几张写满公式和图表的小卡片。画面右侧一个半透明的发光工作流/机器人，正同时处理文件、数字表格、校验清单和图像，动作麻利。中间一道柔光箭头把人的想法传递给机器人。整体传达“人负责想，工具负责干”。无文字，干净留白，比例 16:9 或 2.35:1，适合公众号头图。

## 配图 2 · 路标拦截（放在第二节“最值钱的一单”内，正文 `![图2 路标拦截](assets/04-gate.png)`）

> 概念插画。一座自动闸门/路标立在数据流通道上，闸门上显示红色禁止符号，一组数字“21,963”被挡在门外；旁边绿色通行箭头放行正确数字“7,423”。背景是代码与公式。传达“错误活不过一条命令”。红绿对比，科技感，无多余文字，方图 4:3。

## 配图 3 · 分工信息图（放在第三节“干活姿势”内，正文 `![图3 分工信息图](assets/04-divide.png)`）

> 信息图风格，左右分栏对比。左栏标题“人”，画一个思考的人物剪影，下方三个图标：灯泡（想法）、放大镜（纠错）、天平（判断）。右栏标题“WorkBuddy”，画一个发光的工作流图标，下方四个图标：计算、查错、排版、索引。两栏中间虚线分隔，上方可配文字“对齐分工，活就换了主人”。扁平插画，蓝橙双色，干净，比例 4:3。

## 配图 4 · 复利曲线（放在第四节“为什么是复利”内，正文 `![图4 复利曲线](assets/04-curve.png)`）

> 极简数据可视化插画。同一坐标系两条曲线：一条平缓上升的直线，标注“效率提升（一次性）”；一条早期贴近基线、后期陡峭向上的指数曲线，标注“复利（可累积）”。深蓝背景或浅色背景均可，突出指数曲线后发优势，无多余装饰，比例 4:3。
